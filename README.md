# Hi, I'm Brayan 👋

**ROS 2 Robotics Engineer — autonomous mobile robots, navigation and simulation.**

Mechatronics Engineer (UNI, Peru) with 5+ years building robotics software on ROS 1 and ROS 2 for
autonomous mobile robots in logistics, agriculture and construction. Founder of
[Kalman Robotics](https://kalmanrobotics.io), where I build a ROS 2 robot kit, Gazebo simulations
and a browser-based ROS 2 lab, and have trained 2,000+ engineering students.

🏆 1st place, International Startup Competition (ISC), with an autonomous navigation robot.
